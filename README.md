# 🤖 Codey - AI Coding Assistant Telegram Bot

A feature-rich Telegram Bot built with Python that serves as an intelligent coding mentor, providing automated code debugging, line-by-line code explanation, and general programming assistance.

## ✨ Features
- 🐞 **Smart Code Debugger:** Analyzes errors and explains core bugs with fixes.
- 💡 **Code Explainer:** Breaks down complex code for beginners using intuitive metaphors.
- 💬 **Free Chat:** Context-aware programming discussions powered by LLMs.
- 👥 **User Limits & Usage Tracking:** SQLite-based quota management.
- 🛠 **Admin Dashboard:** In-chat admin management panel for stats and user control.

## 🚀 Tech Stack
- **Python 3.10+**
- **python-telegram-bot** (Async)
- **OpenAI API Client**
- **SQLite3**
